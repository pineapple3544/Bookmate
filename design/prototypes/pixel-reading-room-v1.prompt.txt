Use case: ui-mockup.
Create a polished high fidelity visual design prototype for Bookmate, a Korean shared physical-book reading web app with a walkable pixel-art social reading room. This is a static design concept showing a complete desktop app screen, landscape 1536x1024 composition, no device frame, no promotional collage.
Main experience: large 2D orthographic slightly top-down pixel-art library occupying 72% of screen width, readable HTML-style interface occupying remaining 28% right panel. Strict crisp pixel art in the room, visible square pixel clusters, consistent sprite scale, flat hand-drawn 16-bit aesthetic, no 3D rendering, no isometric diamond floor. Cozy midnight library with dark teal walls, honey walnut parquet, back-wall bookshelves, warm amber reading lamps, a tall window with evening sky, two small plants, clear walkable paths. One central large rectangular wooden shared reading table with four chairs and four distinct cute adult-styled chibi pixel avatars, three seated reading and one standing near empty chair. Thoughtful layering of table and sprites, unobstructed avatar silhouettes. Small mint outlined floor selection tile beneath standing avatar. A tiny book marker over the current book holder. Minimal short nickname labels.
Layout: 72px dark header, small pixel open-book icon and 'Bookmate' wordmark left, '우리의 독서방' center-left, online pill '4명 접속 중' at right. World room framed cleanly with generous space, large enough to feel inhabited and playable. Inside room bottom an understated helper '바닥을 눌러 이동하세요'. Bottom bar below world has three large flat controls '내 기록' (mint primary), '참가자', '방 설정'; subtle chair interaction chip near table '앉기'.
Right sidebar: comfortable readable modern Korean sans-serif text, not pixel font for body. Title '함께 읽는 책', stylized original book cover titled '느린 페이지', small label '현재 책 소유자' and value '낙연'. A clear simple reading order with four named entries '소이', '수빈', '낙연', '민지', showing two completed entries, Nakyeon currently reading, Minji waiting. Then a quiet paper-like personal note preview card titled '내 기록' with 'p. 42' and a short line '천천히 읽어도 괜찮아.' Bottom full width button '독서 완료'. Respect spoiler protection: only show personal note, no other people's record text.
Palette: app background #10191F, surfaces #1D2B34, mint accent #82D9B0, off-white type #F3F6F3, secondary #BECCCF, warm wood and amber restricted to room. Restrained borders, clean type hierarchy, visually calm, beautiful bespoke pixel furniture and human avatars, strong useful interface. No chat bubbles, no metrics clutter, no floating particle effects, no gradients in interface, no glossy 3D, no faux browser chrome, no watermark.
