# 백엔드와 통합 구현 계획

## 1. 기반

현재 서버 기동, DB 연결, 초기 마이그레이션, 공통 응답, OpenAPI와 API 클라이언트를 제공합니다. 초기 DB 모델은 User, Room, RoomMember입니다. 이메일 정규화, 정원과 양수 순서 검사, 마지막 관리자 탈퇴 정책은 업무 API 구현 시 추가합니다.

## 2. 인증과 방

회원가입, 비밀번호 해시, 세션·로그아웃, CSRF, 로그인 요청 제한을 구현합니다. 이어서 방 생성·검색·참가·초대 기능을 추가합니다. 초대 토큰은 만료와 사용 제한을 적용합니다.

완료 기준은 두 사용자의 가입과 초대 참가, 비참가자의 방 정보 접근 거절입니다.

## 3. 독서 진행

책 소유자와 전달 이력을 위한 모델을 추가합니다. 독서 시작·완료·책 전달을 DB 트랜잭션으로 확정합니다. 동시 요청과 재전송에는 버전 검사와 멱등성 키를 적용합니다.

완료 기준은 중복 전달 요청 후에도 책 소유자와 전달 이력이 한 번만 변경되고 두 화면이 같은 상태를 표시하는 것입니다.

## 4. 실시간과 Host

인증된 WebSocket, 같은 방 참가자 간 시그널링, 접속 세션, heartbeat, Host lease, 원자적인 epoch 증가를 구현합니다. 이전 epoch 명령을 거절합니다. 서버 재시작 이후 세션을 재구성합니다.

완료 기준은 A 강제 종료 후 B 승계, A 재접속, 마지막 접속 종료 후 휴면 전환입니다.

## 5. 기록 권한과 P2P 통합

키 관리와 브라우저 암호화 규격을 함께 설계합니다. 미완료 사용자는 자신의 기록을 읽고 타인 기록은 암호문으로 복제합니다. 서버에서 완료 상태를 확인한 후 필요한 키 접근을 허용합니다. 전원 완료 이후의 댓글·그림 이벤트도 검증 가능한 권한 규격을 사용합니다.

이미 전달한 복호화 키와 평문 사본의 회수는 보장할 수 없으므로 완료 취소·탈퇴·키 교체 정책을 이 단계에서 확정합니다.

완료 기준은 미완료 사용자의 타인 기록 복호화 차단, 완료 후 열람, Host 변경 중 복제와 누락 이벤트 복구입니다.

## 6. 배포와 시연

PostgreSQL 백업·복원, 키 보호 비밀값 복구, HTTPS/WSS, TURN 인증·포트·전송량 관리, 외부망 접속을 확인합니다. WSL에서 검증한 이미지를 실제 서버에서 실행하고 두 기기로 시연합니다.
