# 픽셀 독서방 디자인 재진단

2026-11-09 · unslop 부분 다듬기 적용

## 진단

기존 픽셀 방과 색상 방향은 유지할 가치가 있어 전면 재설계 대신 주변 UI를 정리했다.

- 상단: 82px 높이와 테두리 배지가 방보다 먼저 시선을 끌었다.
- 방·책 제목: ROOM 01, BOOK 01의 대문자와 과한 자간이 화면의 한국어 표기와 섞였다.
- 모바일 아바타·보조 정보: 9~10px 텍스트가 작았다.
- 조작부: 문자 기호로 만든 아이콘의 모양과 굵기가 달랐다.
- 버튼: 여러 민트색 강조가 경쟁했다.
- 사이드바: 간격과 행 높이가 불규칙하고 완료 버튼 위에 큰 빈 공간이 생겼다.
- 카드·메타: 반복되는 둥근 테두리와 밝은 메모 면이 픽셀 방과 경쟁했다.

## 방향

- 제품: 함께 읽고 기록과 대화를 나누는 독서방
- 성격: 차분함, 따뜻함, 작은 놀이성
- 배경 소재: 서재의 나무·종이·잉크
- 시선의 중심: 움직이는 픽셀 방과 아바타
- 고유 디테일: 현재 책 소유자를 표시하는 작은 책 표식

## 적용한 아홉 단계

| 단계 | 변경 |
| --- | --- |
| 간격 | 4px 단위 중심으로 통일. 상단 64px/모바일 56px, 참가자 행 48px, 이동 버튼 44px로 정리 |
| 색상 | 어두운 중립색 표면과 세 가지 텍스트 역할로 통일. 민트는 선택 상태, 주요 기록 버튼은 밝은 종이색 사용 |
| 아이콘 | Lucide SVG 18px, 선 굵기 1.5로 책·설정·방향·닫기 통일 |
| 문구 | 독서방 1·책 정보로 표기 통일. 사용자 요청대로 사용자 번호와 임시 문구 유지 |
| 서체 | Noto Sans KR 유지. 과한 자간·굵기 제거, 작은 표시 최소 11px, 입력창 모바일 16px 적용 |
| 배치 | 방 중심의 유동 영역과 280px 사이드바 유지. 완료 버튼을 기록 아래로 배치. 모바일 접기 유지 |
| 세부 요소 | 테두리·곡률·선택·포커스 상태 통일. 숫자·접속 인원은 단순 텍스트로 표현 |
| 시각 요소 | 실제 동작하는 Canvas 픽셀 방을 중심으로 유지. 새 이미지나 이미지 생성 프롬프트는 사용하지 않음 |
| 모션 | 색상 전환 160ms, 모션 감소 설정 반영. 카메라를 transform 이동으로 변경하고 말풍선 위치 계산도 연결 |

## 검증

- 브라우저 폭 320 / 390 / 768 / 1440px: 가로 넘침 없음
- 이동, 착석·일어나기, 기록 저장, 완료 처리 정상
- 모바일 책·참가자·기록 접기, 사용자 선택과 카메라 정상
- 실제 API 채팅 전송, 말풍선 화면 안 배치, 시간 경과 후 사라짐, 채팅창 기록 유지, 재접속 시 과거 말풍선 재생 없음 확인
- 브라우저 JavaScript 오류 없음, JavaScript 구문 검사와 git diff 공백 검사 통과
- 검사에 사용한 채팅 메시지 두 건만 정확한 ID로 삭제
- 검사한 텍스트 명암비: 본문 14.99:1, 보조 8.64:1, 약한 텍스트/올라온 표면 5.56:1, 주요 버튼 12.12:1, 선택 글자 8.04:1
