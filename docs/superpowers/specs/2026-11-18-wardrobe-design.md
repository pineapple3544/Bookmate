# Bookmate 옷장 설계

## 사용자 동선

홈 하단의 ‘내 서재’ 오른쪽에 ‘옷장’을 추가한다. 방에 들어가기 전에도 계정의 기본 캐릭터를 미리 보고 꾸밀 수 있다. 독서방에서는 상단 꾸미기 버튼을 없애고 왼쪽 벽의 작은 의자 자리에 거울과 손잡이가 달린 픽셀 옷장을 둔다. 기존 가구 자리를 써서 테이블과 보행 통로를 확보한다. 옷장 자체를 한 번 클릭하거나 탭하면 현재 사용자의 편집기가 열린다. 키보드로 가구에 초점을 옮긴 뒤 Enter 또는 Space로도 연다.

두 곳은 같은 미리보기, 꾸미기 항목, 저장·취소 동작을 사용한다. 홈에서 저장하면 옷장 탭에 머무르고, 방에서 저장하면 편집기를 닫고 옷장으로 초점을 돌려준다. 취소와 Escape는 편집 전 모습으로 돌아간다. 화면에는 조작에 필요한 이름과 오류 메시지만 둔다. 사용법과 적용 범위를 설명하는 문구는 추가하지 않는다.

## 검토한 방식과 선택

모든 방에 하나의 계정 외형을 실시간 적용하는 방식은 여러 방의 모습이 함께 바뀐다. 사용자는 홈에서 새 방의 기본 모습을 정하고, 이미 참가한 방에서는 따로 옷을 갈아입는 방식을 선택했다.

## 저장 규칙

- 홈 옷장의 저장 대상은 로그인한 사용자 본인의 기본 외형이다. 서버는 방 생성이나 최초 참가가 성공할 때 그 시점의 기본 외형을 참가자 데이터에 복사한다. 기본 외형을 바꾼 뒤 기존 방에 재입장하거나 참가 요청을 재시도해도 기존 모습이 유지된다.
- 방 안 옷장의 저장 대상은 그 방의 내 참가자 외형이다. 다른 참가자는 해당 방에서 갱신된 모습을 본다. 다른 방의 내 모습과 홈 미리보기는 이전 모습을 유지한다.
- 기존 방에서 저장해 둔 외형은 보존한다. 과거에 서버 외형이 비어 있던 참가자는 기존 표시 규칙을 유지하며, 나중에 만든 홈 기본값으로 일괄 변경하지 않는다.
- 기존 의상·코스튬·획득한 책 펫의 선택 및 잠금 규칙을 재사용한다. 체험 모드는 브라우저 저장소를 사용하며 실제 계정 외형과 구분한다. 저장 요청이 실패하면 편집 중인 모습을 보존하고 같은 곳에서 다시 시도할 수 있게 한다.

## UI 평가와 확인 기준

모바일에서는 옷장 그림과 터치 영역을 같은 위치에 고정하고 최소 44 × 44 CSS 픽셀을 확보한다. 화면 이동·확대 시 눌리는 위치와 그림이 일치하고, 옷장을 누른 동작이 바닥 이동으로도 처리되지 않아야 한다. 네 번째 하단 탭은 작은 화면에서도 이름이 보이게 한다. 키보드 초점과 선택된 꾸미기 옵션은 색상 외에도 윤곽이나 선택 표시로 구분한다.

두 계정과 방 두 개로 확인한다. 홈에서 파란 옷을 고르고 A방을 만든 뒤 A방 옷장에서 초록 옷으로 갈아입는다. 다른 참가자에게는 A방에서 초록 옷이 보이고, 홈과 새로 참가하는 B방에서는 파란 옷이 보여야 한다. 홈 기본값을 한 번 더 바꾸고 두 방에 재입장해 각각의 옷이 유지되는지 확인한다. 빈 계정의 첫 사용, 기존 방 재입장, 취소, 새로고침, 모바일 터치와 키보드 조작도 검증한다.
